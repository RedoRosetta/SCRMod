# 使用说明

SCRMod 需要 SCRoot 提供的临时 Root 环境，主要适配 SCR-01 / SM-H412J、Android 11、SCR01KDU1AVK2 固件。

## 版本与获取方式

GitHub Release 提供专版 APK，并公开部分基础功能源码。公开源码不含短信、IMS、授权及 APN 实现，不能重建完整 APK。源码包用于开发与查看，不是安装包，范围见[源码说明](SOURCE_SCOPE.md)，文件校验见[校验说明](VERIFY_DOWNLOAD.md)。

## 短信功能

短信功能依赖三星原生短信 APP，该 APP 并非本项目作者开发。GitHub 专版不附带三星原生短信 APP，如需使用短信功能，请联系作者了解兼容 APP 与授权方式。

本页面不提供三星短信 APP、授权文件或签发工具。请勿在公开 Issue 中提交设备码、号码、短信正文或授权材料。

## 已取得安装包的用户

按作者提供的说明确认安装包来源、版本及使用条件。安装后打开 SCRMod 并授予 Root 权限，再按需调整热点、流量上限及网络设置。同签名更新可保留应用数据；遇到签名冲突或授权异常，请先记录提示，不要直接卸载或清数据。

重启后需重新确认 Root 是否可用，开机自动应用不负责获取 Root。短信配置完成后仍需实际测试发送和接收，组件运行状态不能代替收发结果。

问题反馈要求见[反馈与隐私说明](../SECURITY.md)。
