# SCRMod 1.0 Build58

SCR-01 / SM-H412J 设备功能扩展，主要适配 Android 11、SCR01KDU1AVK2，需要已有 Root 环境。

## 产品更新

Build58 减少重复的授权资源加载和短信组件状态读取，并调整热点页面底部留白。此前版本还改善了横竖屏布局、深色模式和组件状态显示。实际 CPU、内存与耗电改善尚未测量。

以上为完整产品的开发进度，不表示这些功能全部包含在公开源码中。

## 本次公开内容

待发布附件为 `SCRMod-public-source-build58.zip` 及 `SHA256SUMS.txt`。公开副本版本为 **1.0 Build58 Public / 89**，包含93个文件，提供基础界面、热点、流量上限、NAT 检测及只读蜂窝信息等功能。
