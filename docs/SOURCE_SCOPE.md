# 源码公开范围

| 材料 | 公开源码副本 | 完整 APK |
| --- | --- | --- |
| UI、设备检查、Root 执行、热点/信道、数据上限、NAT 诊断 | 包含 | 包含 |
| 短信收发修复、IMS 兼容、后台服务与任务 | 排除 | 保留 |
| 短信注入脚本、Frida 运行程序 | 排除 | 保留；见第三方清单 |
| 短信授权实现及签发工具 | 排除 | 仅含客户端 |
| 三星短信 APK | 不包含 | 不包含 |
| SCRoot APK、提权程序 | 不包含 | 不包含 |
| 私钥、设备记录、内部实验、历史构建产物 | 不包含 | 不新增 |

公开副本将首页、导航、设置、启动和开机任务的短信引用一并移除，能够独立构建基础功能。没有用功能正常的假状态或空实现冒充短信修复。

公开源码版不是完整 APK 的可复现源码。GitHub 自动提供的 Source code.zip / tar.gz 也只对应公开范围。

本次没有为 SCRMod 自有代码指定 MIT/GPL 等许可，版权由作者保留。公开可见不等于已经授予开源许可。第三方代码及资产遵循各自许可证。

## 信道模块

`scr01_idc36` 为 SCR-01 的 36–48 信道支持提供内核补丁，源码见 [kernel/scr01_idc36](../kernel/scr01_idc36/)。模块声明采用 GPL 许可。
