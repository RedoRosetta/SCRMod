# 公开源码范围

短信功能依赖非本项目作者开发的三星原生短信 APP，GitHub Release 提供专版 APK，不附带三星原生短信 APP。如需使用短信，请联系作者了解兼容 APP 与授权方式。

配套公开副本版本为 **1.0 Build58 Public / 89**。它提供部分基础功能，**不能复现完整功能 APK**；公开可见不等于完整开源。

| --- | --- | --- |

| 只读蜂窝信息及设置入口 | 包含 | 包含 |

公开副本仍保留部分历史脱钩首页与设置，其界面不等同于完整 APK。源码包的 93 文件范围由代码维护交付清单确定；页面与说明文件单独维护。不要把整个本地工程作为公开仓库上传。
