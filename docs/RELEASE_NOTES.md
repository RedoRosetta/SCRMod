# SCRMod 1.0 (build12) · 联通 SMS 修复

本次更新重点修复联通 SIM 卡短信收发异常。联通兼容方案已重新整理，测试版本经用户实际使用确认生效，现并入正式版本。

## 更新内容

- **修复联通短信收发：** 加入独立的联通 IMS 兼容策略，并调整接收修复的生效条件。
- **更准确的状态提示：** 区分等待 IMS 注册、已确认注册与兼容异常，方便判断短信链路是否准备好。
- **改善覆盖更新：** 更新后自动替换旧接收脚本，避免继续使用旧方案。

## 更新后怎么用

覆盖安装下方的 **SCRMod-1.0-build12-v41.apk**，保留设置与授权。进入「短信功能修复」，选择「联通」，开启联通兼容并点击「重新配置」，然后分别测试一次接收和发送。

仍需可用的 Root 环境、兼容的三星短信 APP 和相应授权。短信功能继续作为 Beta 提供，不同固件、SIM 和短信 APP 版本的兼容性可能不同。
