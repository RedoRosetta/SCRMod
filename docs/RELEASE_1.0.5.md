# SCRMod 1.0.5

相对1.0.2，本次主要完善短信组件异常恢复和状态判断，减少部分诊断处理，并改进热点设置的保存与恢复。

- **异常恢复：** 完善短信组件初始化失败时的清理，以及发送处理异常时临时状态的恢复，保留原始错误信息。
- **状态判断：** 区分暂时读不到状态与明确失效，在身份和会话核验通过时减少不必要的组件重建；无法确认仍显示待确认，不放宽授权、SIM或会话检查。
- **诊断开销：** 复用同轮部分读取，跳过达到观察上限后的无用计算，减少重复错误日志；既有安全检查及检测周期保留，实际资源和耗电收益尚未量化。
- **热点偏好：** 修正目标频宽保存和实际回读，避免实际20 MHz却误报80 MHz生效。新增默认关闭的“热点重开后恢复”选项，观察到热点重新开启时恢复一次已保存的信道和频宽，已匹配则不重复切换。

热点恢复依赖应用观察到重开事件，应用不活跃时不保证执行；没有持续强制切换，系统仍可能降宽，**不保证永久保持80 MHz**。此前短信转发与来源号码可选等功能保留。

## 验证与已知限制

两份优化构建、完整专版63项和公开副本107项测试、原签名与16KiB对齐检查通过。测试集合有重叠，不合计为独立用例数；已有Node回归属开发证据，未在本次打包中重复执行。

**1.0.5尚未安装或完成设备业务验收。** 真实短信收发、转发、换卡、长待机，以及热点恢复和频宽保持效果仍待验证，历史版本人工通过不扩展到本版。

Phone进程原生崩溃、内存增长和长时间调用的唯一原因仍未确认，**不宣称本次已根治Phone故障**。完整第三方合规及精确组件版本映射仍待核查。

短信、IMS、注入、授权、转发和APN实现继续不公开；自有代码未新增统一开源许可证，第三方材料保留各自许可。
