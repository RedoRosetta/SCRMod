# SCRMod 1.0 Build61

本次更新相对于 Build58，主要改善后台运行，并增加热点频宽设置。

- **后台稳定性：** 修复 Android 11 后台首次初始化订阅监听器时，因线程没有 Looper 而引发的崩溃。
- **后台效率：** 减少重复的包信息查询和不需要的日志处理，保留动态授权、安全校验及原有检测频率。实际资源降幅尚未测量。
- **热点频宽：** 新增 **20 / 40 / 80 MHz** 选择，与信道设置共用“应用”操作，并核对实际频宽；读回不符或无法确认时，不再仅凭信道正确报告成功。保存的频宽可沿用原有开机应用设置。

本次未调整短信收发算法或 APN 策略，也未加入后台反复强制切换频宽的机制。频宽仍受固件、驱动、环境与客户端影响，不保证持续保持 80 MHz；应用热点设置可能使连接短暂中断。

主要适配 Samsung SCR-01 / SM-H412J、Android 11、SCR01KDU1AVK2。
