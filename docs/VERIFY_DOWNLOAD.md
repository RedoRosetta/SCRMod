# 下载校验

以下为待发布公开源码包的 SHA-256。完整功能 APK 暂不在 GitHub 公开提供；如需使用请联系作者。

文件：`SCRMod-public-source-build58.zip`

```text
243c2ec25760326702dc0a2d8b9fb629f4dc8f4a54ed25128e945fd5e4a110ab
```

Windows PowerShell：

```powershell
Get-FileHash .\SCRMod-public-source-build58.zip -Algorithm SHA256
```

Linux：

```sh
sha256sum SCRMod-public-source-build58.zip
```

macOS：

```sh
shasum -a 256 SCRMod-public-source-build58.zip
```

结果应逐字符一致，字母大小写不影响比较。哈希用于核对文件内容，不能代替对来源的确认。源码包不能作为 APK 安装，也不能重建完整功能版本。
