# SCRMod 1.0.2

相对上次公开的 Build61，本次新增短信转发，并改进转发内容的显示方式。新版本改用 1.0.x 命名。

- **短信转发：** 可将新收到的短信转发至指定手机号，支持转发全部短信或仅转发识别为验证码的短信。功能默认关闭，需主动设置目标并授予系统短信权限。
- **验证码筛选：** 支持中文、英文、日文相关规则，属于启发式识别，可能漏判或误判。
- **来源号码可选：** 默认不在转发正文中附加来源号码，也可在设置中手动开启，减少来源数字对接收端验证码识别的干扰；不保证所有接收端均能正确识别。
- 转发保留 SIM 与授权检查、去重和防循环处理；发送结果不明时不自动重发。系统返回已发送不等于目标手机已收到。

不读取或补发历史短信，不改变原有短信收发修补算法、IMS 与 APN 策略。转发由当前 SIM 发送，可能消耗套餐短信额度或产生费用。

## 验证与已知限制

两份优化构建、15项转发专项测试、原签名与16KiB对齐检查通过。公开实现与测试相对Build61未变，仅更新版本；历史101项公开测试未在本次重跑。

用户已确认本地1.0.1转发及1.0.2的实际测试结果，新 GitHub 专版尚未另做安装和业务验收；不扩展为所有运营商、模式、iPhone识别及长期场景通过。

此前Build61过夜出现的Phone进程原生崩溃原因仍未确认，本次转发验收不代表该问题已解决；资源收益和热点长期频宽保持也未新增验证。

短信转发、原短信/IMS/注入/授权/APN继续闭源。自有代码未新增统一开源许可，第三方沿用各自许可，完整第三方合规与精确组件映射仍待核查。
