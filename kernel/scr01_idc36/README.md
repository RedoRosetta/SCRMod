## 用途与适用范围

模块通过临时修改特定内核的 IDC SAP 信道切换路径，为 SCR-01 的 36–48 信道支持提供底层补丁。代码检查原始指令字节，在第二步写入失败时尝试回滚；卸载时尝试恢复原始指令。

地址与指令字节绑定特定内核，不能作为通用 Wi-Fi 驱动或通用信道解锁模块。现有二进制的 vermagic 为 `4.14.186-24165939 SMP preempt mod_unload modversions aarch64`。运行时字节检查也不能替代固件兼容性验证。
