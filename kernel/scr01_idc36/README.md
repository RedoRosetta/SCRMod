# SCR-01 信道支持模块

`scr01_idc36` 为 SCR-01 的 36–48 信道支持提供临时内核补丁。源码见 [scr01_idc36.c](scr01_idc36.c)，应用使用的模块位于 `app/src/main/assets/kernel/scr01_idc36.ko`。

模块修改 IDC SAP 信道切换路径，写入前检查原始指令字节，卸载时尝试恢复原始指令。代码中的地址与指令绑定特定内核，不能用于其他设备或内核版本。

适配内核：`4.14.186-24165939`（ARM64）。
